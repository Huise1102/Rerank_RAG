## 二、验收项逐条结论

### 2.1 认证与会话

| 验收项 | 结论 | 依据 |
| --- | --- | --- |
| 未登录访问业务页面跳转登录页，未携带凭证调用接口返回 401 | 通过 | 路由守卫拦截；`get_current_user` 对缺失凭证返回 401 |
| 管理员登录后进入管理端，侧边栏展示全部页面 | 通过 | 管理端布局含问答、知识库、检索策略、模型配置、日志、反馈处理、用户与权限 |
| 普通用户登录后进入用户端，不出现管理菜单 | 通过 | 用户端仅注册问答与我的反馈路由 |
| 管理员可用同一账号登录用户端，并提供返回管理端入口 | 通过 | 用户端顶部导航含返回管理端按钮 |
| 普通用户登录管理端被拒绝 | 通过 | 路由守卫提示并跳转用户端登录 |
| 退出后旧凭证失效 | 通过 | 服务端会话表撤销，旧令牌再调用返回 401 |
| 禁用用户不能登录，已登录用户下一次请求失效 | 通过 | 登录校验账号状态；鉴权依赖校验会话与用户状态 |
| 连续登录失败触发限流，错误提示区分具体原因 | 通过 | 账号不存在、密码错误（含剩余次数）、账号禁用、锁定（含等待时长）分别提示，实测第 6 次触发 429 并提示 10 分钟后重试；已记录账号枚举风险 |
| 密码哈希存储，日志无明文密码与完整令牌 | 通过 | bcrypt 12 轮；日志只记录用户名与动作 |
| 首次登录或重置密码后强制改密 | 通过 | 登录响应带 `must_change_password`，前端弹出不可关闭的改密框 |

### 2.2 权限分配

| 验收项 | 结论 | 依据 |
