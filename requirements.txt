# 环境：Python 3.11.9 (Windows x64)    已实测安装并验证通过
#
# 安装方式（推荐 uv，明显快于 pip）:
#   uv venv --python 3.11 .venv
#   uv pip install --python .venv\Scripts\python.exe -r requirements.txt
#
# GPU 加速：默认装 CPU 版 torch。若有 NVIDIA 显卡，先执行
#   uv pip install --python .venv\Scripts\python.exe torch --index-url https://download.pytorch.org/whl/cu121
# 再安装本文件，embedding 与 rerank 会自动使用显存（合计约需 4 GB）。
#
# -----------------------------------------------------------------------------
# ⚠️ 重要版本约束说明（版本矩阵经过依赖求解验证，请勿随意放宽）
# -----------------------------------------------------------------------------
# 1) pydantic 必须 <2.10（本文件锁 2.9.x）
#    langchain-core 0.2.x 的内部模型仍使用 pydantic v1 风格的 `class Config`，
#    该写法在 pydantic 2.10 中被彻底移除，会直接抛
#    `PydanticUserError: Please use 'model_config'`。
#
# 2) chromadb 必须 <0.6（本文件锁 0.5.x）
#    所有支持 chromadb 1.x 的 langchain-chroma 版本（>=0.2.4）都要求
#    langchain-core>=0.3.60，与 LangChain 0.2.x 硬冲突。因此定位到
#    与 LangChain 0.2.x 兼容的最后一组：langchain-chroma 0.1.4 + chromadb 0.5.20。
#
# 3) 不使用 FlagEmbedding
#    bge-reranker-v2-m3 已被官方标注为 sentence-transformers 库（pipeline:
#    text-ranking），直接用 sentence_transformers.CrossEncoder 加载即可，
#    无需引入 FlagEmbedding 及其 datasets/accelerate/peft 等约 1.5 GB 传递依赖。
# =============================================================================
